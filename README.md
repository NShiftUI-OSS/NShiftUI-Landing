# NShiftUI-Landing

Documentação pública do NShiftUI numa única página: Rainbow, Android, iOS, o repositório de demonstração e o CLI.

O GitHub Actions publica GitHub Pages a cada push em `main`.

```bash
npm install
npm run dev
```

O `base` do Vite é `/NShiftUI-Landing/`.
